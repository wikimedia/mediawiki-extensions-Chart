# Contributing to Chart

## Welcome

Thank you for your interest in contributing to Chart.

This guide describes the main ways contributors can help. We are always open to
contributions in the following forms:

- Bug reports and bug fixes
- Documentation improvements

At this time, we do not accept feature requests.

### Overview

Chart is a MediaWiki extension that provides interactive data visualization
capabilities for Wikimedia wikis. Learn more about the
[architectural decisions](doc/adr/),
[Chart extension](https://www.mediawiki.org/wiki/Extension:Chart) and
[project background](https://www.mediawiki.org/wiki/Extension:Chart/Project).

For installation and local setup, refer to the
[README](README.md).

### Community engagement

Refer to the following channels to connect with fellow contributors or to stay
up-to-date with news about Chart:

- Participate in discussions in the [Village Pump][village-pump].
- Stay updated on the latest news and changes by following
  [MediaWiki's version lifecycle][version-lifecycle].

## Contributing

### Code of conduct

Before contributing, read our
[Code of Conduct](CODE_OF_CONDUCT.md)
to learn more about our community guidelines and expectations.

### Bug reports

We use [Phabricator](https://phabricator.wikimedia.org/tag/charts/)
to track tasks and bug reports. To report a bug:

1. Search for existing issues: Check if the issue has already been reported
   in Phabricator.
2. Create a new issue: If the issue doesn't exist, create a new issue on
   Phabricator through the Create Task dropdown.
3. Provide details: Include:
   - A clear description of the issue
   - Steps to reproduce
   - Expected vs. actual behavior
   - Your environment (MediaWiki version, browser, etc.)
   - Screenshots or error messages if applicable

### Proposals and feature requests

To share an idea for the project:

1. Create a task on [Phabricator](https://phabricator.wikimedia.org/tag/charts/).
2. Describe your proposal clearly, including the problem you're trying to solve.
3. Wait for feedback from maintainers before starting implementation.

### Code contribution

Chart uses [Gerrit][gerrit] for code review. For local setup, coding
conventions, testing, and development workflow, refer to the [README][readme].
For Gerrit workflow and general MediaWiki contribution practices, refer to the
[Gerrit/Tutorial][gerrit-tutorial] and
[How to become a MediaWiki hacker][mw-hacker].
